## 6. 형상관리 제외 대상
`config.json`, `.env`, `*.key`, `*.cert`, `logs\`, `CVE\`, 인증 폴더, 빌드 산출물은 Git 제외 대상이다. 단, 현재 Git 작업트리에 다수 수정·미추적 파일이 있으므로 배포 기준선과 산출물 보관정책을 구분해야 한다.
