## 4. 성능·가용성 요구사항
- 대시보드 집계 테이블과 인덱스를 사용한다.
- DB 풀은 동시 연결을 제한·관리한다.
- 외부 API·AI 호출에는 타임아웃·재시도·요청간격을 적용한다.
- 장기 작업은 웹 요청과 분리한다.
- 정량 SLA, RTO, RPO, 최대 동시 사용자, 처리량은 **미정 — 승인 필요**.

## 5. 데이터 요구사항
- 문자셋 utf8mb4
- 핵심 CVE 코드·링크·hash_key 중복 방지
- 시간대는 DB 저장 기준과 화면 KST 표시 기준을 명확히 구분
- 개인정보·인증정보는 최소 수집과 암호화 적용
- 로그 보존은 접속 1~2년, 권한 5년 등 조직 정책 반영

## 6. 미결정사항
- 사내 AD/SSO 연동 방식
- 사용자·관리자 허용 IP
- 공식 도메인·포트·TLS 종단
- 백업 주기/RPO/RTO
- 중앙 SIEM·V3·SecuMS·QueryOne 연계
- 서비스 책임자 및 비상연락망
