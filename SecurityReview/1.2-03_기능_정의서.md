## 2. 역할별 기능
| 역할 | 주요 기능 |
|---|---|
| 비로그인 | 로그인·가입·계정찾기, 공개 대시보드/CVE/PoC 일부 |
| user | 조회, 프로필, 평가·댓글·채팅 |
| analyst | user + 허용 테이블 DB 조회 |
| admin | 사용자·역할·설정·로그·API 토큰·AI 할당량·재분석 |
| 운영자(OS) | 서비스·DB·수집·분석·백업·장애조치 |
| 외부 API 사용자 | 토큰 권한 범위의 Export |

## 3. 주요 오류 처리
- 입력 오류: HTTP 400
- 인증 없음/실패: 401
- JWT 무효·권한 부족: 403
- 데이터 없음: 404
- 동시 장기작업: 429
- 서버/DB 오류: 500
- AI 연속 실패: 쿨다운 상태 파일로 장시간 중지 가능

## 4. 알려진 기능 결함·위험
- `POST /api/db/query` 중복 등록 및 후행 구현의 검색필드 검증 위험
- `DELETE /api/admin/users/:id` 중복 등록
- `GET /api/poc/:id/rating` 선택적 인증 미들웨어 부재
- Export confirm의 write 권한 검사가 주석 처리된 상태
- 인증코드가 debug 로그에 노출될 수 있음
- 최소 비밀번호 길이·계정잠금·세션통제 미달
