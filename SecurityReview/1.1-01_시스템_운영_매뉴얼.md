# 1.1 시스템 운영 매뉴얼

## 1. 문서 개요
- 목적: CVE_BOT의 안정적인 운영, 점검, 장애 대응 및 인수인계 기준 제공
- 적용 범위: `C:\aiserver\CVE_BOT` 애플리케이션, 웹, DB, 수집·분석 프로세스, 스케줄러, 로그
- 기준일/버전: 2026-07-21 / 1.0
- 운영시간 및 SLA: **미지정 — 조직 승인 필요**

## 2. 시스템 목적
CVE_BOT은 GitHub·CIRCL·CVE API에서 취약점과 PoC 정보를 수집하고, AI로 PoC를 분석하여 패킷·공격단계·MITRE ATT&CK·Snort 룰·대응방안을 생성한 뒤 웹으로 조회·관리하는 시스템이다.

1. Windows·디스크·메모리·시간 동기화 상태 확인
2. MySQL80 상태 및 DB 접속 확인
3. PM2의 caddy/backend/frontend 상태 확인
4. 웹 로그인·대시보드·CVE 목록 조회 확인
5. Python 수집·AI 분석 프로세스 중복 및 최근 로그 확인
6. 대시보드 집계 작업의 최근 실행 결과 확인
7. 오류·할당량·쿨다운·미처리 건수 확인
8. 백업 성공 여부 및 복구 가능성 확인
9. 점검 결과와 조치 내역 기록

## 6. 운영 명령
명령은 관리자 또는 승인된 운영자 계정에서 실행한다.

```powershell
Set-Location C:\aiserver\CVE_BOT\web
pm2 status
pm2 logs cve-backend --lines 100
pm2 logs cve-frontend --lines 100
pm2 logs caddy --lines 100
Get-Service MySQL80,W32Time
Get-ScheduledTask -TaskName CVE_BOT_Dashboard_Init
```

Python 프로세스 확인:

```powershell
Get-CimInstance Win32_Process |
  Where-Object { $_.CommandLine -match 'CVE_BOT|run_ai_analysis|collector' } |
  Select-Object ProcessId,CreationDate,CommandLine
```

## 8. 보안 운영 주의사항
- 문서나 티켓에 비밀번호·토큰·개인키를 기록하지 않는다.
- 기본 관리자 계정, 하드코딩 비밀값, DB 계정은 현행 위험사항으로 별도 개선 관리한다.
- RDP·WinRM·MySQL·내부 Node 포트의 전역 노출은 방화벽/보안그룹 기준으로 제한해야 한다.
- Defender 제외 경로로 인해 프로젝트 파일 검사가 누락될 수 있으므로 보안부서 승인 여부를 확인한다.
- V3·SecuMS·QueryOne은 현재 호스트에서 확인되지 않았다.
