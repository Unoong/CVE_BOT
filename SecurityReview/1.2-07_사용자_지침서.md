# 1.2 사용자 지침서

## 문서 정보
- 기준일/버전: 2026-07-21 / 1.0
- 대상: 일반 사용자(user), 분석가(analyst), 관리자(admin)

## 1. 접속
1. 조직에서 승인한 CVE_BOT URL로 접속한다.
2. HTTP 직접 포트가 아닌 HTTPS 주소를 사용한다.
3. 개인 계정으로 로그인한다.
4. 공용 admin 계정을 일상 사용하지 않는다.

## 2. 회원가입
1. 이메일 입력 후 인증코드 요청
2. 3분 안에 인증코드 입력
3. ID, 이름, 닉네임, 전화번호, 비밀번호 입력
4. 가입 완료 후 로그인

현행 프로그램은 4자 이상 비밀번호를 허용하지만 사용자는 사내 정책에 따라 영문·숫자·특수문자를 조합한 8자 이상 비밀번호를 사용해야 한다. 동일 비밀번호 재사용을 피한다.

## 3. 주요 메뉴
| 메뉴 | 사용 방법 | 역할 |
|---|---|---|
| 대시보드 | 전체 CVE·PoC·AI 현황과 추이 확인 | 전체 |
| CVE 정보 | 검색·심각도·상태·정렬 필터 | 전체 |
| CVE/PoC 상세 | CVE 설명, 관련 PoC, AI 분석·Snort 확인 | 전체 |
| 주의 취약점 설정 | 주의대상 설정 조회 | 로그인 |
| 프로필 | 닉네임·비밀번호 변경 | 로그인 |
| DB 조회 | 허용 테이블 검색·페이징 | analyst/admin |
| 로그 | 운영 로그 조회 | admin |
| 관리자 | 사용자·역할·비밀번호 관리 | admin |
| API 토큰 | 토큰 생성·중지·삭제 | admin |
| AI 할당량 | 계정별 사용·오류 확인 | admin |

## 4. CVE 검색
- CVE 코드, 제품, 설명으로 검색
- 심각도·상태·PoC/AI 존재 여부 필터
- 최신순, 게시일, 수집일, CVSS 점수 정렬
- 상세에서 PoC 링크와 AI 분석 단계를 확인

## 5. PoC 취급 주의
- PoC 링크와 파일은 실제 공격코드일 수 있다.
- 업무용 격리환경 외에서 실행하지 않는다.
- 서버에서 직접 PoC를 실행하지 않는다.
- 다운로드·외부반출은 조직 승인 절차를 따른다.
- 악성 의심 파일은 정보보호 담당자에게 통보한다.

## 6. 평가·댓글
- 로그인 사용자는 PoC에 평가와 댓글을 등록할 수 있다.
- 본인 댓글만 수정·삭제하며 관리자는 정책상 필요한 조치를 수행할 수 있다.
- 개인정보, 비밀번호, 토큰, 내부 IP·구성정보를 댓글에 남기지 않는다.

## 7. 계정·비밀번호
- 타인과 계정을 공유하지 않는다.
- 비밀번호를 브라우저·문서·메신저에 평문 저장하지 않는다.
- 의심 로그인이나 비밀번호 노출 시 즉시 운영자에게 통보하고 변경한다.
- 자리 비움 시 수동 로그아웃한다. 현행 시스템에는 유휴 자동 로그아웃이 없다.

## 8. 오류 발생 시
운영자에게 다음 정보를 전달한다.
- 발생 시각
- 접속 URL과 메뉴
- 입력 조건(CVE 코드 등, 비밀값 제외)
- 오류 메시지
- 재현 절차
- 화면 캡처(개인정보·토큰 마스킹)

브라우저 개발자도구의 JWT·API 토큰을 공유하지 않는다.

## 9. 금지사항
- 비인가 DB 조회·대량 Export
- API 토큰 공유 또는 URL 쿼리로 전달
- PoC 무단 실행·반출
- 관리자 기능 우회
- 로그·데이터 임의 삭제
- 비밀정보를 게시판·채팅·이슈에 기록
