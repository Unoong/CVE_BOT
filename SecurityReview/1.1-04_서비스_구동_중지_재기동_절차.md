# 1.1 서비스 구동·중지·재기동 절차

## 문서 정보
- 기준일/버전: 2026-07-21 / 1.0
- 원칙: DB → 웹 → 배치/분석 순으로 시작하고 역순으로 중지한다.
- 주의: 명령 실행 전 변경 승인과 작업 공지를 확인한다.

## 1. 사전 확인
```powershell
Get-Service MySQL80,W32Time
Get-NetTCPConnection -State Listen |
  Where-Object LocalPort -in 80,3000,3001,32577,32578,7002
Get-CimInstance Win32_Process |
  Where-Object CommandLine -match 'CVE_BOT|run_ai_analysis'
```

중복 Python 분석 프로세스가 있으면 어떤 프로세스가 현행 코드로 시작되었는지 확인한다. 실행 중 Python은 디스크 변경을 자동 반영하지 않으므로 코드 변경 후 반드시 승인된 재기동이 필요하다.

## 2. 정상 구동

### 2.1 DB
```powershell
Start-Service MySQL80
Get-Service MySQL80
```

### 2.2 웹스택
```powershell
Set-Location C:\aiserver\CVE_BOT\web
pm2 start ecosystem.config.js
pm2 status
```

PM2 목록이 이미 있으면:
```powershell
pm2 restart cve-backend
pm2 restart cve-frontend
pm2 restart caddy
pm2 status
```

### 2.3 대시보드 집계
자동 작업은 조사 시 `CVE_BOT_Dashboard_Init`으로 매일 02:00 실행된다. 수동 실행은 승인 후 작업 스케줄러에서 실행하거나 다음 배치를 사용한다.

```powershell
Set-Location C:\aiserver\CVE_BOT\web
.\run_init_dashboard.bat
```

### 2.4 AI 분석
중복 실행이 없는지 먼저 확인한 뒤 프로젝트의 승인된 Python 환경에서 실행한다.

```powershell
Set-Location C:\aiserver\CVE_BOT
python .\run_ai_analysis.py
```

현재 AI 분석은 Windows 서비스나 작업 스케줄에 등록되지 않은 수동 프로세스다. 콘솔 종료, 사용자 로그오프, 재부팅 시 복구 여부를 보장하지 않는다.

## 3. 정상 중지

### 3.1 AI 분석
- 새 분석 시작을 중단하고 진행 중 작업 종료를 기다린다.
- 정상 종료 방법이 없는 대화형 실행은 해당 콘솔에서 `Ctrl+C`를 사용한다.
- PID를 확인하지 않은 일괄 `taskkill /IM python.exe`는 다른 업무를 중단할 수 있으므로 금지한다.

### 3.2 웹스택
```powershell
Set-Location C:\aiserver\CVE_BOT\web
pm2 stop cve-backend
pm2 stop cve-frontend
pm2 stop caddy
pm2 status
```

### 3.3 DB
웹과 Python의 DB 작업이 끝난 뒤 중지한다.
```powershell
Stop-Service MySQL80
Get-Service MySQL80
```

## 4. 재기동
1. 작업 공지 및 영향 확인
2. 최근 로그와 현재 PID 기록
3. AI 분석 → 웹 → 필요 시 DB 순으로 중지
4. DB → 웹 → AI 순으로 시작
5. 상태·포트·웹·DB·로그 검증
6. 결과 기록 및 작업 종료 공지

## 5. 구동 후 검증
```powershell
pm2 status
Get-Service MySQL80,W32Time
Get-NetTCPConnection -State Listen |
  Where-Object LocalPort -in 80,3000,3001,32577,32578,7002
```

기능 검증:
- `https://<승인된 도메인>:3000` 로그인 화면
- 로그인 및 `/api/auth/me`
- 대시보드 통계
- CVE 목록·상세
- 관리자 로그 화면
- 최근 백엔드 오류 없음
- AI 분석 로그에 현행 명령 형식이 기록됨

## 6. 현행 제약
- PM2는 Windows 서비스가 아니며 `pm2 startup` 결과 Init system이 없어 자동복구가 확인되지 않았다.
- `dump.pm2`도 조사 시 확인되지 않았다.
- `run_ai_analysis.py`는 수동 장기 실행이다.
- 재부팅 후 자동 시작을 가정하지 말고 반드시 수동 검증한다.
