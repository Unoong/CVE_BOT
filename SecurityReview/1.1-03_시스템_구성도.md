## 4. 주요 데이터 흐름
1. GitHub PoC 검색·다운로드 → `Github_CVE_Info` 및 `CVE\` 파일
2. CIRCL/CVE API 조회 → `CVE_Info`
3. 미분석 PoC → AI CLI → `CVE_Packet_AI_Analysis`
4. 세 데이터 집합 조합 → `CVE_Integrated_Data`
5. 집계 배치 → `dashboard_*`
6. Express API → React 화면/외부 Export API

## 5. 신뢰경계
- 외부 인터넷 ↔ 수집기: 외부 콘텐츠와 PoC 파일 유입
- 사용자망 ↔ Caddy: 인증·TLS·접근통제 경계
- Caddy ↔ Node 내부 포트: 현재 전역 바인딩으로 경계 약함
- 애플리케이션 ↔ MySQL: root 계정과 전역 DB 바인딩 위험
- 관리자 ↔ RDP/WinRM: Public 방화벽 허용 상태
