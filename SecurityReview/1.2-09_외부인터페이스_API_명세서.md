- 기준일/버전: 2026-07-21 / 1.0

## 2. 웹 인증
### JWT
- 헤더: `Authorization: Bearer <JWT>`
- 발급: `POST /api/auth/login`
- 페이로드: id, username, role
- 유효기간: 24시간

### API 토큰
- 권장 헤더: `X-API-Token: <token>`
- 쿼리 `api_token`도 코드상 지원하지만 URL·프록시 로그 노출 때문에 사용 금지 권장
- 활성·만료·permissions 확인

## 4. 공통 응답
- 성공: JSON, HTTP 2xx
- 입력 오류: 400
- 인증 실패: 401
- 권한/JWT 오류: 403
- 없음: 404
- 중복 실행/제한: 429
- 서버 오류: 500

오류 객체 키는 `error`, `message`, `success` 등 라우트별 차이가 있어 연동 시스템은 HTTP 상태와 본문을 함께 처리해야 한다.

## 5. Socket.IO·파일
- Socket.IO: 실시간 채팅
- `/api/chat/upload-image`: JWT, multipart `file`, 이미지 MIME, 최대 10MB
- `/uploads/*`: 업로드 파일 제공

## 6. 네트워크 정책안
| 구간 | 허용 |
|---|---|
| 사용자 → Caddy | 승인 사용자망에서 HTTPS 3000 또는 표준 443 |
| Caddy → frontend/backend | localhost 전용 3001/32577 |
| 앱 → MySQL | localhost 7002 |
| 운영자 → RDP/WinRM | 관리망·승인 IP만 |
| 수집기 → 외부 API | 승인된 도메인 HTTPS |
| W32Time → NTP | AWS 또는 사내 NTP |
