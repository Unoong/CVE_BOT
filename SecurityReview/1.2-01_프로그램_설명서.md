# 1.2 프로그램 설명서

## 문서 정보
- 기준일/버전: 2026-07-21 / 1.0
- 시스템: CVE_BOT

## 1. 프로그램 개요
CVE_BOT은 공개 취약점과 GitHub PoC를 자동 수집하고 AI 분석 결과를 데이터베이스에 적재하여 대시보드, 검색, 상세 분석, 관리자 기능 및 외부 Export API로 제공한다.

## 2. 기술 구성
| 계층 | 기술 |
|---|---|
| 수집·분석 | Python 3, requests, mysql-connector, Gemini/Antigravity CLI |
| 웹 API | Node.js, Express, MySQL2, JWT, bcrypt, Socket.IO |
| 프론트엔드 | React, Vite, MUI, Recharts |
| DB | MySQL/InnoDB, utf8mb4 |
| 프록시/TLS | Caddy |
| 프로세스 | PM2, Windows 작업 스케줄러, 수동 Python |
| 형상관리 | Git/GitHub |

## 3. 업무 처리 흐름
1. GitHub API에서 CVE PoC 검색
2. 저장소 메타·README·파일 수집
3. CIRCL/CVE API에서 공식 CVE 정보 수집
4. 미분석 PoC를 AI CLI에 전달
5. 단계별 패킷·취약점 단계·MITRE·Snort·대응방안 저장
6. 통합 테이블과 대시보드 통계 생성
7. 웹과 Export API로 조회·관리

## 5. 인증·권한
- JWT 유효기간: 코드상 24시간
- 역할: `user`, `analyst`, `admin`
- 외부 Export: API 토큰의 read/write 권한
- 비밀번호: bcrypt

현행 제약:
- 앱 비밀번호 최소 4자
- 로그인 실패 잠금, 90일 미사용 잠금, 유휴 세션, 멀티로그인 차단 없음
- 기본 admin 계정 자동 생성

## 6. 설정
| 파일 | 용도 |
|---|---|
| `config.json` | DB·GitHub·수집·기본 역할 등 |
| `config.test.json`, `config.prod.json` | 환경별 설정(존재 시) |
| `ai_analysis_config.json` | 병렬·요청 제한·재시도·크기 제한 |
| `prompt.txt`, `prompt_instruction.txt` | AI 프롬프트 |
| `web/logger.config.json` | 웹 로그 레벨 |
| `web/ecosystem.config.js` | PM2 앱 |
| `web/Caddyfile` | 프록시·TLS |

비밀정보는 설정 파일에 직접 보관하지 않고 승인된 시크릿 저장소로 이전해야 한다.

## 7. 데이터 저장
핵심 테이블은 `Github_CVE_Info`, `CVE_Info`, `CVE_Packet_AI_Analysis`, `CVE_Integrated_Data`이며 사용자·PoC 상호작용·API 토큰·AI 할당량·대시보드 집계 테이블이 추가된다. 상세는 `1.2-06_테이블_명세서.md` 참조.
